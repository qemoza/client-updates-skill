# The facts sheet

The skill fills this in before it writes. You can also fill it in by hand and paste it to Claude.

Each line says where it came from. If a part is empty, leave it empty.

```
Client: {first name}. Covers: {the day or the week}.
Call with them today: {yes, no or not known}

ALREADY SAID (they know this, leave it out)
- 

FACTS
- [board, finished] 
- [code, shipped] 
- [board, in progress] 
- [call, {day}] 
- [channel] 
- [accounts, {period}] 
- [log] 

THEY ASKED (questions from the client with no answer yet)
- 

WAITING ON THEM
- 

HELD BACK (real work the client does not need to read)
- 
```

## How to fill it in

- One fact per line. Say what is now true for the client.
- If something is still being tested, write that on the same line.
- Copy numbers, names and dates exactly.
- `THEY ASKED` is for questions the client is still waiting on.
- `WAITING ON THEM` is only for things you are really blocked on.
- `HELD BACK` is for work that is real but that the client does not need to read.

No tools connected yet? Write five lines at the end of your day. That is enough to start.
